# data/

Loaders and seed definitions for synthetic patient data (Synthea CSV, seeded scenarios S1 to S5, generated notes), and `sample_reports/`: generated lab and prescription PDFs plus one scanned PNG, with `expected.json` listing what extraction must find (`gen_sample_reports.py`, using `pdfmaker.py`). Generated and downloaded files (`raw/`, `synthea/`) are gitignored; scripts regenerate them from a fixed seed. All data is synthetic.
